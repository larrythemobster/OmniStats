# Contributing to OmniStats

OmniStats is a Windows app for Rocket League stats, built with C++20. Bug fixes, UI improvements, and docs are welcome.

- Keep PRs focused. Discuss big features, architecture changes, and new dependencies first.
- Understand and test what you submit. Include screenshots for UI changes.
- Follow [.editorconfig](.editorconfig). For C++, run `clang-format -i <changed-files>` from `Client/` using the included [.clang-format](.clang-format). Don't reformat unrelated code.
- Don't add cheats, anti-cheat bypasses, hidden data collection, or weaker security.
- Never commit secrets or private user data. Report vulnerabilities privately.

See the [build guide](docs/BUILDING.md) for setup.

OmniStats is [source available](LICENSE), not open source. The [contribution exception](CONTRIBUTION_EXCEPTION.md) permits contribution forks, not unofficial releases or rebrands. By contributing, you accept its terms and confirm you have the right to submit your work.
